# 0.2.0

Release type: first JSONB accessor.

## Purpose

This release adds the first C function. `jsonb_slice_get(jsonb, text)` reads
one top-level object field. Its result matches PostgreSQL's `jsonb -> text`
operator.

## Included

- a PostgreSQL shared library;
- one immutable, strict, parallel-safe C function;
- support for every JSONB field value type;
- SQL null, missing-field, and non-object behavior;
- a fresh 0.2.0 installation script;
- an upgrade script from 0.1.0;
- regression tests for the function and package;
- versioned documentation and release automation.

## Not included

- partial TOAST reads;
- a text-returning accessor;
- array-index or path accessors;
- operators or planner behavior;
- benchmark results;
- support for a production database.

The function detoasts the complete input before it reads the JSONB object
directory. This release makes no performance claim.
