# 0.1.0

Release type: installable project shell and research definition.

## Purpose

This release defines the experiment. It contains no JSONB read code. The
extension package can be installed, inspected, tested, and removed.

## Included

- a precise problem statement;
- a PGXS build file and extension control file;
- a versioned SQL installation script;
- an install and removal regression test;
- a PostgreSQL-style C format configuration and CI check;
- versioned documentation;
- automated version, package, documentation, and Pages checks;
- a tagged source archive with a SHA-256 checksum.

## Not included

- JSONB accessors or planner behavior;
- C source or a shared library;
- SQL functions or operators;
- benchmark results;
- support for a production database.
